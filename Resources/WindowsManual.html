Sound Canvas Bridge for Windows

Sound Canvas Bridge 1.4.1 for Windows provides a standalone MIDI sound module and a 64-bit VST3 plug-in for an existing legitimate Sound Canvas VA installation. No Roland engine or ROM is included.

Installation

Run the Windows installer. It places the standalone in Program Files/OnjMusic/Sound Canvas Bridge and the VST3 in Program Files/Common Files/VST3/Sound Canvas Bridge.vst3. Save your work, stop MIDI playback and unload the bridge from audio hosts before choosing Install. The installer requests administrator approval, checks both components before replacing either, and restores previous components after a failed replacement. Settings, NKS presets and Roland files are not replaced. Unexpected or modified files in an existing installation are preserved by refusing the replacement.

The standard setup wizard has Next, Back, Install and Finish buttons. Desktop and Start-menu shortcuts are selected by default on the first installation; updates remember your choices. Tab moves between the shortcut checkboxes, and Space changes the selected option. Sound Canvas Bridge is registered in Windows Installed Apps. The final page offers Open Sound Canvas Bridge, which honours Start hidden and closes the installer when you finish. Desktop and Start-menu shortcuts explicitly show the controls. Existing desktop and login shortcuts to the earlier local copy are redirected to the shared installation. Shortcuts can also be added from General preferences. An older portable copy remains available but is not used by those migrated shortcuts.

Standalone Part offers All (Sound Map). Choosing All alone changes no sound. The next Sound Map choice applies to all 16 parts without changing their bank, program, mixer or effects. Other per-part controls are unavailable until a numbered part is selected; global effects remain editable. The map field represents the last broadcast request, not a promise that later MIDI has left every part unchanged. The VST3 and NKS Part parameter remains numbered 1 to 16.

Apply an All-parts map while stopped: the native engine reselects each current bank and program in the new map. As with a normal program change, kit-specific drum edits can return to that kit's defaults. Changing maps is not a substitute for restoring a saved scene.

Windows update checks use only the Windows release family and verify its RSA signature before opening the installer. Missing, invalid or wrong-version signatures stop the update. This is OnjMusic's update signature, not a Microsoft-trusted Authenticode certificate; Windows may still show an unfamiliar-publisher warning. The installer does not change Windows security settings.

First Launch

Use Ctrl+, to open Preferences. Preferences stays inside the main window. General contains update and startup choices, the Sound Canvas VA location, Browse and Download from Roland. Audio and MIDI contains driver, output, sample rate, device buffer and MIDI inputs. First launch and missing-engine recovery open General automatically. Browse selects the original 64-bit SCCore.dll from your own Sound Canvas VA installation, not the bridge VST3.

Download from Roland remains available even when an engine is installed. After licence confirmation, a native helper downloads Roland's official trial archive, verifies the archive, installer and extracted files, and retains the 64-bit engine and its required app-local Microsoft runtime. Neither installer is run and no system runtime is installed. Progress and cancellation are available. The files are kept outside the bridge installation in your SoundCanvasBridge profile. A completed import offers to restart the standalone engine; existing hosted instances keep their engine until reloaded. Unavailable, changed or failed downloads do not replace the active engine choice. Roland may change or remove this archive; Browse remains available.

A plug-in loaded before engine setup displays instructions to open the standalone app and use Preferences, General. Attempting realtime note playback can show that guidance once per host session; passive plug-in scans and offline rendering do not open setup prompts. Downloads are never performed inside an audio host.

Choose ASIO for your manufacturer's driver, or Windows Audio for WASAPI. Driver settings opens the manufacturer's control panel when supported. The bridge does not open microphone input. Enable the required MIDI inputs using their checkboxes. Selections are saved. Release held notes before disabling an input.

The native Windows virtual-device feature is not included in this package because current Windows builds can hang the MIDI service when the device closes, and its SDK remains a development preview. See Microsoft's virtual-device issue. System MIDI inputs remain available, including ports created with an existing loopback utility. This installer does not install or configure a loopback driver automatically. When QWS sends to a loopback port, leave that same port disabled as a QWS input to avoid a MIDI Thru loop.

Keyboard Navigation

In REAPER with OSARA, F6 hands keyboard focus into the plug-in window. The editor exposes Control page as its initial keyboard target; Tab then continues through the controls. The host remains responsible for the F6 handoff.

Tab and Shift+Tab move through the active view. In Preferences they reach both category buttons, the active page and Close. Left/Right Arrow selects another category while a category button is focused. Home and End select the first or last category. Escape or Close returns to the sound controls and restores focus. Category and Close controls do not announce extra instructional hints.

Browse presets and Current sound use concise screen-reader labels. In standalone, F1 reads their instructions on request instead of announcing them on every visit. The preset browser retains searchable names, map/type filters and F1 address details.

The Control page menu selects the sound, tone, effects, drum or insertion controls. Part selects which of the 16 MIDI parts those controls edit. Multitimbral routing preserves incoming MIDI channels; Selected Part redirects channel messages to the chosen part. SysEx passes through unchanged. Drum kits normally use part 10; their detailed drum controls select the setup and note to edit.

On a numeric slider, arrows change one step, Page Up/Down change ten, and Home/End select the limits. Enter opens direct value entry. Enter confirms; Escape discards unconfirmed text. Tab confirms and moves on. Program is displayed from 1 to 128. Bank is a variation from 0 to 127; the compatibility map is selected separately.

Desktop and Startup

Add desktop shortcut is in General preferences. Both this and Run at login reuse a complete local installation if one already exists, even when you are running the portable copy. Otherwise they offer a local installation in the current user's Local AppData Programs folder, under OnjMusic/Sound Canvas Bridge. Cancel leaves the requested shortcut unchanged. The portable copy is kept. The application copies and verifies only its own support files; it does not copy Roland files, samples or settings, and refuses to overwrite a different local installation.

The startup shortcut targets the local application, never the removable portable copy. Disabling Run at login removes only the bridge's matching startup shortcut. The original Roland engine must still be available at its configured path; moving or disconnecting that drive can prevent synthesis even when the bridge itself is installed locally.

The desktop shortcut explicitly shows the controls. If the bridge is already hidden in the system tray, opening the shortcut restores the existing application instead of starting another engine. Start hidden controls ordinary launches, login launches and the installer's Open Sound Canvas command; opening the desktop shortcut overrides it for that launch. Application settings are stored separately and shared by normal standalone and VST3 instances.

Closing the main window, Alt+F4, Ctrl+Q and File > Exit fully close the application and stop playback. To leave playback running, explicitly choose View > Hide to System Tray or Ctrl+H. Windows may put the tray icon among hidden icons; opening the desktop shortcut restores the controls without starting another engine. The tray menu also offers Exit.

Latency and Effects

A saved audio interface is never silently replaced with the Windows default. If its driver is busy, disconnected or cannot open the saved settings, the app retains your selection, shows Audio/MIDI Preferences and reports the error. First-run setup can use the system default. Hidden startup is suspended when audio or the synthesis engine needs attention.

The shared bridge latency defaults to 128 samples, ranges from 32 to 2048 in steps of 32, and is separate from the audio device buffer. Existing settings are preserved. Lower values need more scheduling headroom; increase the value if your system cannot keep up. Change it while stopped to avoid a brief gap. Engine Status reports effective delay, scheduling gaps and missing samples.

The plug-in exposes 93 controls, including part mixer and tone settings, shared reverb/chorus/delay/EQ, per-note drum editing and native insertion effects. Insertion Type selects Thru or one of 64 algorithms. Part MFX routes a selected part through that shared effect. Detailed insertion slots remain numbered because their meanings depend on the algorithm; unused slots have no audible effect. Advanced readback is enabled only for a verified compatible engine build.

Preset Browser

The current sound name above the parameter rows is a selector: Up and Down load adjacent sounds in the current map and sound type, announcing their names. Enter opens the searchable browser, also available from Presets. Filter its 2,958 named addresses by name, sound map and Programs or Drums. Browser rows announce only the sound name; F1 opens the full address details. Escape or Back returns to the same row. Selecting a browser row does not change the sound until Enter, Load or a double-click. Escape or Close returns to the controls.

Loading preserves mixer settings and effects and uses an existing suitable part without changing melodic/drum assignments. The current part is preferred; otherwise programs prefer part 1 and kits prefer part 10 when suitable. In standalone All mode, first select a numbered part. The VST3 deliberately retains one native host program: a global factory list can reinterpret channel-specific MIDI program changes as global recalls. Use the internal browser or NKS instead. The 93 automation controls and existing NKS identities remain unchanged.

New scenes retain all part-role assignments. Older scenes use their historical default roles. Default-role scenes keep the older encoding, but custom-role scenes require the updated bridge.

The standalone installs grouped VST3 preset files for the current user when it starts. Help, Install DAW Presets repeats this if needed. The files appear under Documents/VST3 Presets/OnjMusic/Sound Canvas Bridge, directly grouped as Programs or Drums, sound map and, for programs, instrument family, without a Factory wrapper. Custom presets can be kept alongside the two installer-managed groups. An older generated Factory bank is migrated only after its complete contents are verified. DAW support for disk-preset folders varies. These files recall their saved default mixer and keyboard-routing settings, unlike the internal browser which preserves current mixer/effects. Unrelated or edited files are retained rather than overwritten; installation problems are recorded in the standalone log.

NKS and Links

The separate OnjMusic NKS collection contains Sound Canvas presets under Roland. Instrument and drum presets are grouped by compatibility map. Their named addresses can share underlying samples. Previews and favourite identities are independent of standalone settings.

Product page, Contact and Donate are also available from Help. Automatic checks notify you; installation always requires confirmation.

Limits and Removal

The plug-in supports processing blocks up to 4096 samples and individual SysEx messages up to 65536 bytes. The standalone splits larger device buffers into supported blocks. Advanced readback recognises the verified engine build; other builds retain basic playback with advanced controls unavailable.

To remove the bridge, first disable Run at login and unload it from audio hosts. In Windows Settings, open Apps, then Installed Apps, choose Sound Canvas Bridge and Uninstall. The uninstaller closes the standalone normally and removes the verified bridge app, VST3 and setup-created shortcuts. If a host still has the VST3 open, or an installed file was modified, removal stops without deleting unknown files. User settings remain in AppData/Roaming/OnjMusic/SoundCanvasBridge; NKS presets, previews and the original Roland installation are not removed. Separately created portable copies and shortcuts are not part of this installation.
