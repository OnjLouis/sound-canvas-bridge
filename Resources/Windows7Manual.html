Sound Canvas Bridge for Windows 7

This portable edition runs on Windows 7 SP1 with the secure DLL-loading updates from KB2533623 or a later update that includes them. It uses its own settings and shortcuts. It does not replace the modern Windows installer.

Setup

  1. Extract the whole ZIP. Keep all of the files in Application together. Open Sound Canvas Bridge.exe before opening the plug-in in a host.
  2. In Preferences, General, use Browse to select the original SCCore.dll. Use an engine of the same architecture as the bridge, and keep its runtime beside it. Download from Roland is also available if the system can connect to Roland over HTTPS. No Roland engine or ROM is included.
  3. In Audio and MIDI, select an audio output and the inputs you use. Play test phrase checks the selected output. Use a physical MIDI input or an existing software port; this edition does not install a virtual MIDI driver.
  4. For VST3, copy the entire Sound Canvas Bridge.vst3 folder to a folder scanned by your compatible VST3 host. The plug-in must match the host's architecture. Do not install the modern and legacy versions in the same host: they share the same plug-in ID.

Keyboard and screen reader

Tab and Shift+Tab move between controls. Control+comma opens Preferences, F1 opens focused-control help, F9 sends All Notes Off, and Control+Q quits. Escape closes help, preferences or the browser. Use the application menu for reset, activity and tray commands.

Musical Keyboard (Control+K) auditions the selected part in the standalone. A S D F G H J K L, semicolon and apostrophe play white notes; W E T Y U O P play sharps. Z/X change octave, and C/V change velocity. The Octave and Velocity sliders appear only with the keyboard. All auditions the last numbered part. The keyboard pauses and releases notes during direct value entry and preset search. Escape closes the keyboard. VST3 uses the host's MIDI keyboard.

Part shows each numbered part and its current sound, for example 1: Piano 1. Moving between parts doesn't load or reset sounds. All remains available in the standalone for changing the Sound Map across all parts.

On Part, Current sound and Control page, arrow keys step, Page Up and Page Down move ten entries, and Home and End go to the limits. Press Enter on Current sound to open the searchable preset list. Slider values can be stepped or typed with Enter. A Windows 7 screen reader may say "alert" after an announced change; the bridge does not use its own speech synthesiser for those changes.

Updates and presets

Shift+F1 checks for a Windows 7 release matching this build's architecture. Set the automatic check interval under Preferences, General. A check can open the release page, but never downloads or replaces program files. If Windows 7 cannot connect over HTTPS, use the GitHub releases page in a supported browser. Check the published SHA-256 before extracting the ZIP. Close the bridge and any host using it before replacing the full Application folder and VST3 bundle. Keep your user settings and original engine separate.

Grouped VST3 presets are included. The Sound Canvas NKS pack is separate and requires a compatible Komplete Kontrol installation.
