Sound Canvas Bridge Guide

Sound Canvas Bridge 1.4.2 provides universal Mac AU and VST3 front ends, a standalone MIDI module and a named-address NKS catalogue for an existing Sound Canvas VA installation.

In the standalone app, Part offers All (Sound Map) followed by parts 1 to 16. Choosing All alone changes no sound. Your next Sound Map choice applies to all 16 parts, preserving their banks, programs, mixer and effects. Other part-specific edits are unavailable until you select a numbered part. Global effect controls remain available. The map choice shows the last broadcast request; subsequent incoming MIDI can override individual parts. AU, VST3 and NKS keep their existing numbered Part parameter.

F9 sends All Notes Off. If macOS assigns F9 to a system action, use Fn+F9 or change that system shortcut so the key reaches the app. Command+M retains Minimise, so GM Reset uses Command+Shift+M. Command+H retains standard Hide; the distinct menu-bar-only mode uses Command+Shift+H. Other action shortcuts use Command without Shift; Command+comma opens Preferences.

Apply an All-parts map while stopped: the native engine reselects each current bank and program in the new map. As with a normal program change, kit-specific drum edits can return to that kit's defaults. Changing maps is not a substitute for restoring a saved scene.

All also sets each part's default map. GS Reset and rewind return to that choice rather than SC-8820. Explicit map choices in incoming MIDI still take precedence; Bank Select LSB zero returns to the selected default. Default maps are retained in saved scenes. Older scenes remain readable; scenes using custom defaults require 1.4.2 or later.

Find the Presets

Download the separate Sound Canvas Bridge pack from OnjMusic NKS, in the Roland folder. Merge its User Content and NI Resources folders into the corresponding Native Instruments folders. After installation, scan Komplete Kontrol's plug-ins and User library. Browse User, Roland Cloud, Sound Canvas, then Programs or Drums. Each bank has SC-55, SC-88, SC-88 Pro and SC-8820 compatibility-map subbanks. Instrument families are category tags rather than further bank nesting. Preset names and identities are retained when mappings are updated, preserving existing favourites.

Built-in Preset Browser

The current sound name above the parameter rows is a preset selector. Up and Down load adjacent sounds in the current map and sound type, announcing their names. Enter opens the searchable browser; F1 shows the current address. The Presets button also opens the browser, with all 2,958 named addresses available without Komplete Kontrol. Filter by sound map and Programs or Drums. Browser rows announce only the sound name; F1 opens map, type, bank and one-based program details on request. Escape or Back returns from details to the same row. Searching and selecting a browser row do not change playback; Enter, Load or a double-click loads the chosen sound. Escape or Close returns to the controls.

A sound change preserves mixer settings and shared effects. It uses the selected part when its existing melodic/drum role matches, otherwise an existing suitable part, preferring part 1 for programs or part 10 for kits. It never changes a part's role or forces channel 10 to be drums. With All selected in the standalone, choose a numbered part before opening the browser.

The standalone installs grouped native presets for the current user at startup: .aupreset on Mac and .vstpreset on Windows. Help, Install DAW Presets can repeat the operation. On Mac they are stored under ~/Library/Audio/Presets/OnjMusic/Sound Canvas Bridge; on Windows, under Documents/VST3 Presets/OnjMusic/Sound Canvas Bridge. Programs and Drums are directly inside that product folder, followed by sound map and, for programs, instrument family. There is no extra Factory level. Custom presets can be kept alongside these two installer-managed groups. Existing links to the standard location are resolved without changing the links. This avoids a flat 2,958-entry AU menu and does not put Windows .vstpreset files in Logic's folders. An older generated Factory folder or duplicate in Logic's Plug-In Settings folder is retired only after its complete inventory and contents match the canonical bank; edited or unrelated banks are retained. Native disk presets recall their saved default mixer and routing settings; the bridge's own browser instead preserves current mixer/effect settings.

The AU reports the current sound name to the host when our browser changes it; a saved Logic channel-strip setting is separate and may retain its own name. Previous/next commands and folder presentation depend on the host and its keyboard configuration. VST3 keeps a single native program to avoid reinterpreting channel-specific MIDI program changes as global recalls. Existing NKS presets, mappings, favourites and previews do not need replacing.

There are 2,872 melodic entries and 86 drum-kit entries, each with a preview. These are named addresses across four compatibility maps, not 2,958 different underlying samples or unique instruments. The SC-8820 subbank offers the broadest selection.

Controls

The bridge exposes 93 controls. The matching NKS pack requires bridge 1.1.0 or later. NKS melodic presets have 13 pages; kits have 12. Controls on each page follow the order listed below, starting at knob 1. Shared effect settings affect all parts in an instance; part sends affect only the selected part. The original pages retain their order.

Drum presets initially route keyboard notes to part 10. Kick is MIDI note 36 and snare is 38. The Drum page selects a note for editing, not for audition: play that note on your keyboard. Insertion Type selects Thru or one of 64 native algorithms. Part Enable, also called Part MFX on the original pages, routes the selected part through this shared effect. It is not a separate effect for each part. The detailed shared reverb, chorus and delay controls are separate effects; To Reverb, To Chorus and To Delay send the insertion effect's output to them. EQ routes that output through the shared EQ.

Parameter selects a slot from 1 to 20 without changing its value. Value edits the selected slot. The three following pages edit those same slots directly. Readouts follow the engine, including incoming SysEx. Parameter functions and scales depend on the algorithm; slots remain numbered with raw values from 0 to 127, not misleading fixed names or physical units. Some slots are unused by particular algorithms. Selecting a different Type recalls its native defaults; set the type before editing its parameters. Use the Sound Canvas VA manual's insertion-effect tables to identify each slot.

Signed controls announce plus and minus. Transpose and bend range use semitones; EQ gains use decibels. Other effect numbers use the GS parameter's native units where the name does not specify a physical unit; they must not be interpreted as seconds or hertz.

Keyboard Use Without Komplete Kontrol

The Control page menu selects Main, Tone, Master, Reverb, Chorus, Delay, EQ, Drums, Insertion or either Insertion Parameters page in the plug-in window. Changing this page does not change the sound. Tab and Shift-Tab move through the page menu, Presets, current sound name, that page's named controls, the shared latency setting and Engine Status, without separate unnamed value fields. On a focused numeric slider, Up or Right increases one step; Down or Left decreases one step. Page Up and Page Down change ten steps. Home and End select the limits without wrapping. Keyboard value changes request immediate screen-reader announcements. Sound Map and Keyboard Routing use choice menus.

Press Enter on a numeric slider to open its named value field. Enter confirms typed input; Escape discards unconfirmed text. Tab confirms and moves to the next control; Shift-Tab confirms and moves to the previous control. Up/Down and Page Up/Down also adjust the value while this field is open. Left/Right and Home/End navigate the text. Already-applied arrow changes remain when cancelling unconfirmed text. Invalid or empty input leaves the value unchanged. Closing the editor discards unconfirmed text.

Program is displayed and entered from 1 to 128. Bank is the Sound Canvas bank variation, from 0 to 127, not a combined 14-bit bank number; Sound Map is selected separately. Latency arrows step by 32 samples and Page Up/Down by 320. VoiceOver's modified navigation keys retain their usual handling.

Requirements

macOS 12 or later is required. Apple Silicon uses a native compatibility worker with a supported owner-supplied 32-bit Windows SCCore.dll. Native Logic, Komplete Kontrol and the standalone do not require Rosetta. Intel Mac hosts retain the original Mac synthesis backend and require their legitimate Sound Canvas VA VST installation, including its core and ROM resources. No Roland binary is bundled with the bridge.

Advanced controls support the verified original and downloadable engine builds, including the older downloadable core's effects and insertion controls. File identity and readable memory ranges are checked before accessing engine state. Unknown Windows DLL builds are rejected rather than guessing their layouts.

Engine Setup on Apple Silicon

General preferences shows the actual DLL path. Browse selects a supported 32-bit SCCore.dll, not a 64-bit DLL or Mac VST. Keep that engine's required Microsoft runtime files beside it. This choice is shared by the standalone, AU and VST3 and is separate from the original Intel Mac VST setting. Restart existing instances after changing it. Engine files stay outside the bridge bundles.

Download from Roland in General preferences remains available when an engine is already installed. After licence confirmation, the native helper downloads the official Windows trial archive, verifies its exact size and SHA-256 identity, and extracts the supported 32-bit SCCore.dll and its required runtime without running either Windows installer. Progress and cancellation are available. Both files are stored under the current user's SoundCanvasBridge application-support folder, outside every app and plug-in bundle. A completed import offers a standalone engine restart; other loaded plug-in instances keep their current engine until reloaded. Cancellation, unavailable or changed downloads and extraction failures do not replace the active engine choice. Roland may change or remove the archive, so Browse remains available. No Roland download or Microsoft engine runtime is included in the bridge package.

First launch and missing-engine recovery open General automatically. A plug-in without an engine directs you to the standalone app for setup. Realtime note playback can show this guidance once per host session; passive scans and offline rendering do not open setup prompts. Downloads never run inside an audio host.

Editor and Playback

AU and VST3 are installed in the shared system plug-in folders. The AU works directly in Logic without Komplete Kontrol. The plug-in window has named controls with values, help and keyboard focus. Sound Map and Keyboard Routing are choice menus. Engine Status reports readiness, requested and effective delay, and errors.

On a focused choice menu, including Current sound and Control page, Up/Down select adjacent entries, Home/End select the first/last entry, and Page Up/Page Down move back/forward ten entries. Navigation stops at the limits without wrapping. Current sound loads the selected sound immediately; Control page only changes the displayed controls.

Standalone

The standalone app receives all 16 MIDI channels and SysEx through a virtual MIDI input named Sound Canvas Bridge. Choose that destination in your sequencer. It is a sound module, not a MIDI-file browser, and has no onscreen keyboard. The port exists only while the app is running.

Preferences is available with Command+comma. General contains update and startup choices and engine setup. Audio and MIDI contains the output device, sample rate and audio-device buffer. Its MIDI inputs section lists the system's hardware and software inputs as checkboxes; enable any keyboards or interfaces you want to receive alongside the always-available virtual destination. Selections are saved for the next launch. Refresh devices updates the list without rebuilding unchanged entries. Release held keys before disabling an input; Panic is available if needed. No microphone input is enabled.

When a sequencer already forwards your keyboard into the virtual port, leave that keyboard's direct input unchecked to avoid receiving the same notes twice.

On Intel Mac hosts, Sound Canvas VA location displays the installed original VST bundle. Browse selects another installation, checks its identity and required engine resources, then saves the choice for the standalone app and plug-ins. Choose the whole .vst bundle, not an individual .dylib. A new selection offers Restart Engine with Defaults; stop playback before accepting. Existing instances keep their current engine until restarted. A saved path that goes missing is reported rather than silently replaced.

Play test phrase auditions a short piano phrase through a temporary Sound Canvas engine and the selected output, rather than a generic sine tone. It does not change your current programs, parts or effects. Press Stop test phrase to end it early. The temporary engine is released after the phrase. The separate bridge latency remains shared with AU and VST3; audio settings and the standalone sound session are stored separately from the plug-in bundles.

The View menu shows or hides a colourful 16-channel activity display with Command+D. It represents recent note-on events, with velocity-weighted fading lights, not an exact DSP voice count or audio-level meter. It does not add continuously changing screen-reader controls. Command+I reads a quiet snapshot on request.

The MIDI menu separates All Notes Off from Panic: All Sounds Off (Command+P). All Notes Off can leave sustained sound; Panic stops voices without resetting programs or effects. GS Reset (Command+G) and GM Reset (Command+Shift+M) are available separately. Restart Engine with Defaults (Command+R) creates a fresh engine and can recover even if incoming SysEx disabled normal reset reception. Resets require confirmation and do not change the audio device, device buffer or shared latency. Stop external MIDI playback before resetting.

F1 opens selectable, read-only multiline help for the focused control. Arrow keys review the text; Shift with arrows selects text and Command+C copies it. Escape or Command+W closes help and restores the previous control. The main window initially focuses Control page. Preferences focuses the first control on its selected tab. VoiceOver's help-tag command reads the separate control help text. Hover tooltips show a short hint, disappear after three seconds or keyboard use, and do not keep reopening over the same stationary pointer.

Hide to Menu Bar (Command+Shift+H) hides the windows and Dock icon while audio and physical/virtual MIDI keep running. Closing the controls window also hides it rather than quitting. The Sound Canvas Bridge status item offers Show Controls, Preferences, Panic and Quit. Show Controls or reopening the application restores the controls and Dock icon. Quit is the action that stops playback and removes the MIDI destination; hiding is not quitting.

Updates and Startup

General preferences offers Never, At startup, Hourly and Daily update checks. Daily is the default. Hourly and Daily check on launch only when overdue, then while the application remains open. The last check time is saved, so restarting does not force another check before it is due. Shift+F1 and Check for Updates always allow an immediate check. Background failures are logged without interrupting playback; manual checks display the result.

Updates never install silently. An available update offers to download and verify the universal DMG, then opens the same installer used for a fresh installation. The installer replaces the standalone, AU and VST3 together, preserves settings and presets, and restores previous bundles if replacement fails. Stop MIDI playback and close audio hosts before choosing Install. Packages must pass the expected Developer ID, bundle identity, version, architecture and notarisation checks. Unsigned replacements are rejected. Before the first release is published, a check reports that no public release is available.

Run at login and Start hidden in menu bar are separate checkboxes, both off by default. Run at login creates only the bridge's own per-user LaunchAgent; disabling it removes that registration. Start hidden restores saved audio and MIDI settings without showing the controls. Use the menu-bar item or reopen the app to show them. If the engine, audio output or status item is unavailable, the app remains visible for recovery instead.

Cleanup never forces a busy disk image to unmount. If macOS still holds an update image after the bounded retries, the temporary download is retained and the result is recorded in UpdateCleanup.log in the app's log folder. Cancelling the installer does not change installed files or interrupt ongoing playback.

The Help menu contains the offline manual, Version History, Product Page (Command+F1), Contact and Donate.

The application, AU, VST3 and helper contain Apple Silicon and Intel slices. Native Apple Silicon playback uses the compatibility worker without Rosetta; Intel hosts use the original Mac engine backend. Changing the standalone audio output preserves the live engine, including settings outside the mapped controls. The engine retains its initial sample rate for the session. Matching rates use the direct output path; JUCE converts only when the newly selected device uses a different rate, using complete engine quanta rather than tiny fragments. Conversion can read ahead by up to 31 engine samples. A device change can briefly interrupt audio while the device closes and opens.

Default Latency

Fresh settings default to 128 samples: approximately 2.9 milliseconds at 44.1 kHz or 2.67 milliseconds at 48 kHz, in addition to your audio device and host delay. Its slider ranges from 32 to 2048 samples in 32-sample steps. This default is saved per user and shared by AU and VST3 instances; switching NKS sounds does not reset it. Other open instances update when the setting changes. Existing preferences are preserved.

A saved audio interface is never silently replaced with the system default. If that output cannot open, the app retains your selection, shows Audio/MIDI Preferences and reports the error. First-run setup can use the system default. Hidden startup is suspended when audio or the synthesis engine needs attention.

32 and 64 samples are low-latency options to audition on your own system, not a promise of glitch-free performance in every host or project. Use 128 as a starting point. At 48 kHz the bridge portion alone is about 0.67 milliseconds at 32 samples; the audio device and host add their own delay. The bridge setting is separate from the host's audio-device buffer, even if both use the same number.

The bridge delay stays at your chosen value when the host changes its processing block size. Selecting a different track should not silently increase the bridge's latency or insert delay padding. Engine Status shows the actual value. Use a higher setting if the computer cannot keep up. Adjust while playback is stopped: deliberately changing the delay while playing may cause a brief gap. Hosts can compensate for the reported delay during playback; live keyboard playing still includes it.

Engine Status reports the host block size, offline flag and missing-sample count to help distinguish a scheduling failure from normal instrument silence. The bridge handles buffered tracks delivered in bursts without silently increasing the chosen latency. A stopped or overloaded helper can still cause dropouts; the bridge never waits indefinitely.

Multitimbral MIDI and SysEx

A fresh AU or VST3 instance defaults to Multitimbral, preserving incoming MIDI channels and drum channel 10. The NKS presets deliberately select a keyboard part instead: drum presets route keyboard notes to channel 10. Choose Multitimbral routing for externally sequenced multi-part MIDI. System Exclusive messages pass to the original engine, including messages during playback. Compatibility is determined by that engine, not a new approximation of Roland's sound generation.

Saved scenes include the melodic or rhythm-setup assignment of all 16 parts. Earlier scenes load with their historical reset defaults. Default-role scenes retain the version-2 encoding; custom assignments use version 3 and need the updated bridge. A scene is not a complete SysEx dump: keep external initialisation in the project for unmapped settings.

Low-latency performance depends on the computer, audio device and host. Increase the setting if a project cannot keep up, rather than assuming every system can use the minimum.

Part, Routing and Help

Part selects the MIDI part edited by the sound and mixer controls. Changing Part views that part's settings without resending its program or overwriting its edits. It is not a mute or solo control. Multitimbral routing preserves incoming MIDI channels; Selected Part redirects channel messages to the chosen part. Changing Part in Selected Part routing stops notes on the old part to avoid hanging keyboard notes. System Exclusive messages pass through unchanged in both modes.

Hover tooltips and native accessibility help explain each control's scope and units. Supported incoming controllers, including modulation and expression, update the displayed values without being echoed back as new MIDI commands. The refresh is independent of whether the editor is open.

Verification and Limits

All 2,958 complete native preset containers passed state-recall checks; 153 fresh-instance audio checks passed. Every preview was decoded and checked for valid audio, onset and peak headroom. The timing update passed exact event-boundary transport tests; the original synthesis engine still has its own voice-onset behaviour. The 38 supplied SC-88 MIDI files passed bounded opening-section smoke tests, not full-song or hardware-equivalence comparisons.

The catalogue covers every explicit named address in the installed tables, excluding selected-map aliases. Saved state includes the exposed settings across 16 parts and both 128-note drum setups, not just the currently selected drum. It also stores the insertion algorithm, all 20 parameter slots, its sends, EQ routing and two controller source/depth pairs. Old bridge scenes remain readable. This is not a complete dump of every engine parameter: keep external MIDI initialisation in your project, particularly other custom SysEx and receive-channel changes. Active notes and effect tails are not saved. Unknown scene formats are rejected rather than partially applied. Not every host, core version or hardware setup has been tested.

The download contains OnjMusic's bridge code, not Roland's core or ROM files. It is intended for owners with an existing legitimate Sound Canvas VA installation.

Processing Limits

The plug-ins support processing blocks up to 4096 samples and individual SysEx messages up to 65536 bytes. The standalone splits larger device buffers into supported blocks. Advanced readback is limited to the verified engine build described above.
