Sound Canvas Bridge Version History

1.4.3 - 5 November 2026

  • Choice controls, including Current sound and Control page, support Home and End for the first and last entries, and Page Up and Page Down for ten-entry jumps without wrapping.
  • Keyboard selection changes retain immediate screen-reader value notifications. All-parts Sound Map navigation uses the last requested map consistently.
  • No audio-engine, settings-format, NKS, preview or automation changes.

1.4.2 - 4 November 2026

  • Windows preset-browser keyboard entry and selection changes now focus the named row for screen readers instead of leaving accessibility focus on the list container.
  • Windows checkboxes expose a normal checked state and toggle action without the misleading read-only text value. Existing Enter activation is unchanged.
  • All-parts map selection now sets the native default map, which survives GS Reset and MIDI rewind. Explicit MIDI map changes still take precedence.
  • Saved scenes retain each part's default map. Existing version 1, 2 and 3 scenes remain readable; scenes with custom map defaults use version 4 and need this build or later.
  • A successful updater-to-installer handoff no longer leaves an unnecessary modal OK dialog. Errors and manual update-check results remain visible.
  • Existing NKS files, previews, favourite identities and all 93 automation controls are unchanged.

1.4.1 - Windows

  • Fix an in-app update failure where the waiting setup launcher kept the installation folder open, preventing replacement. Setup and update workers now use explicit staging working directories.
  • Browse presets and Current sound keep their instructions in F1 help rather than automatically reading them on Windows. Control names, sound names and keyboard navigation are unchanged.
  • No audio-engine, settings, NKS, preview or automation changes. Mac 1.4.0 is unaffected by this Windows-specific installer fault.

1.4.0

  • Searchable named program and drum browser, current sound names and grouped native AU/VST3 preset files instead of an oversized flat AU menu.
  • Arrowable current-name selector, concise browser rows and on-request address details; native accessibility help for preset controls.
  • Native preset groups open directly at Programs and Drums, without a Factory wrapper; verified migration preserves custom presets and restores both groups if replacement fails.
  • Native Apple Silicon playback no longer requires Rosetta. Intel Mac hosts retain the original Mac engine backend.
  • Windows and native Apple Silicon standalone builds offer a verified official engine download in General, beside Browse. Native extraction includes the required external engine runtime, with progress, cancellation and protection of the working engine. No Roland engine or Microsoft engine runtime is bundled.
  • First launch and missing-engine recovery open General. Hosted plug-ins direct users to standalone setup without downloading inside an audio host or interrupting scans and offline rendering.
  • Hosted keyboard-focus entry reaches the controls without relying on standalone focus recovery.
  • Sound changes preserve mixer/effect settings and existing part roles, with coherent selection and save/recall handling.
  • Saved scenes retain custom melodic/drum assignments; older scenes remain readable. Existing NKS files, previews and the 93 automation controls are unchanged.
  • VST3 native factory lists remain disabled to avoid changing per-channel MIDI program handling; its built-in browser is available.

1.3.0

  • Windows uses a standard setup wizard with Next, Back, Install and Finish, optional desktop and Start-menu shortcuts, and an Installed Apps entry.
  • Windows installation retains recovery copies until the complete wizard succeeds. Uninstall verifies and removes the bridge app and VST3 while keeping settings, NKS presets and Roland files.
  • Mac installation verifies normal standalone shutdown before replacement, including hidden operation, with bounded waiting and clearer diagnostics. Audio hosts are never forced to close.
  • No synthesis, controller, saved-state, NKS mapping or preview changes.

1.2.0

  • Windows x64 standalone and shared VST3 installer, with signed payload/update verification and transactional rollback.
  • Standalone Part selector adds All for sound-map changes across all sixteen parts without broadcasting unrelated edits.
  • F9 All Notes Off and shorter Control/Command shortcuts, with the standard Preferences shortcut retained.
  • All-parts sound-map arrows continue from the last request on both platforms; Mac Preferences includes both category tabs in keyboard navigation.
  • The Part selector keeps its explanation in F1 help instead of automatically announcing it. Windows installer Open respects the saved hidden-start preference and closes the installer.
  • Saved audio outputs no longer silently fall back to a different interface; startup failures retain the selection and explain the error.
  • Update helper replies are bounded UTF-8, including long release notes and error messages.
  • Native sound reselection makes All-parts map changes audible immediately. Standalone editor replacement now clears the previous active editor correctly.
  • Existing VST/AU automation parameters, saved scenes, NKS identities and previews remain unchanged.

1.1.0 - 2 November 2026

  • Insertion-effect algorithm selection, all 20 raw parameter slots, reverb/chorus/delay sends and EQ routing.
  • A parameter selector and value pair, plus direct controls for each slot, with native-engine readback.
  • Four extra NKS pages for every sound and kit, preserving existing pages, preset identities and previews.
  • Insertion settings included in saved scenes, with older bridge scenes still supported.

1.0.0

  • Universal Mac standalone, Audio Unit and VST3 front ends for an existing owner-installed Sound Canvas VA engine.
  • Sixteen-part MIDI and SysEx playback, physical and virtual MIDI inputs, and a saved audio-output selection.
  • Accessible controls, VoiceOver help, keyboard value entry, live controller readouts and detailed tone, drum and system-effect pages.
  • Shared adjustable bridge latency, with output-device changes preserving the live engine and MIDI settings.
  • Menu-bar operation, optional hidden startup and Run at login, plus recovery settings when the engine or audio output is unavailable.
  • General and Audio/MIDI preferences, scheduled update checks, and a common verified DMG installer for all three formats.
  • Bundled help, version history, test phrase, MIDI activity display, panic and confirmed reset commands.

Before 1.4.0, the original Intel synthesis engine required Rosetta on Apple Silicon. Roland libraries are not included.
