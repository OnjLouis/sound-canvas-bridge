Sound Canvas Bridge Version History

1.0.0

  • Universal Mac standalone, Audio Unit and VST3 front ends for an existing owner-installed Sound Canvas VA engine.
  • Sixteen-part MIDI and SysEx playback, physical and virtual MIDI inputs, and a saved audio-output selection.
  • Accessible controls, VoiceOver help, keyboard value entry, live controller readouts and detailed tone, drum and system-effect pages.
  • Shared adjustable bridge latency, with output-device changes preserving the live engine and MIDI settings.
  • Menu-bar operation, optional hidden startup and Run at login, plus recovery settings when the engine or audio output is unavailable.
  • General and Audio/MIDI preferences, scheduled update checks, and a common verified DMG installer for all three formats.
  • Bundled help, version history, test phrase, MIDI activity display, panic and confirmed reset commands.

The original Intel synthesis engine still requires Rosetta on Apple Silicon. Roland libraries are not included.
